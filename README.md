# SNP 데이터 분석 방법 다변화 - 위상적 데이터분석(TDA)에 의한

*SNP: 단일 뉴클레오티드 다형성(single neucleotide polymorphism). 염기서열 중 하나의 염기가 달라지는 유전적 변이

*TDA: 위상학적 데이터분석(topological data analysis). 데이터의 특성과 데이터에 대응하는 도형의 위상학적 성질을 연관지어 분석하는 방법론

<h1>개요</h1>

- 사람 개인의 (생물학적) 국적을 인간 염색체 여러 위치들의 SNP 정보를 조합하여 추정할 수 있음이 잘 알려져 있음
- 해당 분석 과정에 TDA를 도입함으로써 개선가능한 부분이 있는지 확인하고자 하였음
- 미공개 데이터셋 사용

<h1>결과 및 논의</h1>

(`report.pdf` 에도 설명되어 있음)

- 개인의 출신지를 3개 지역(동북아, 동남아, 서남아)으로 분류하는 데 있어, 간단한 기계학습 모형으로도 기존 통계적 방법론의 성능을 따라잡을 수 있음
- 표본공간(sample space)가 아닌 특성공간(feature space), 즉 데이터셋 내의 개인들 대신 유전자좌(locus)들에 TDA를 사용하여 자명하지 않은 관찰을 얻음.
   * TDA에 의해, 주어진 수십 개 이상 유전자좌들이 구성하는 어떤 도형과, 이 중 선택된 일부의 유전자좌들이 구성하는 도형의 차이를 측정할 수 있음. 구체적으로는 존속 호몰로지(persistence homology)와 바서스타인(Wasserstein) 거리를 사용.
   * 개인의 출신지를 3개 지역으로 분류할 때, 주어진 유전자좌들의 일부만으로 추정하면 일반적으로 분류 정확도는 떨어질 수밖에 없음.
   * 그러한 정확도 감소는 앞서 설명한 도형 간의 차이와 상관관계를 보임. 다시 말해, **모양이 적게 바뀌도록 유전자좌를 선택하면 정확도도 덜 감소하는 경향이 있음**.
- 위 관찰에는 다음과 같은 한계가 있음.
   * 결과가 특정 데이터셋, 지역 분류에 한정되어 있음. 다른 데이터셋에서 민족 분류에 대해서는 추가 검증을 요함.
   * 위에서 설명한 상관관계는 통계적으로 유의하나 상관계수의 값 자체는 무척 작음. 그러므로 이 결과는 실용가능한 방법보다는 TDA의 가능성으로서 받아들이는 것이 바람직함.

<h1>저장소 구성</h1>

(`/byungchang/` 하위의 주요 파일들 위주로 설명)
- `tda_feature_selection.ipynb`: 위에서 설명한 정확도 감소에 관한 상관관계 분석 실험
- `distance.ipynb`: 기하학적인 관찰 내용
- `mapper.ipynb`: TDA의 mapper를 통한 관찰 내용
- `utils.py`: 데이터 로더
- `other/lung.ipynb`: 다른 SNP 데이터셋에 대한 같은 실험에서 비슷한 결과를 확인한 파일
